#  Cursor 确认安全漏洞导致出现了恶意 Claude Code 扩展程序

                    Rhinoer  犀牛安全   2026-11-17 16:00

Cursor 证实其遭遇安全漏洞，黑客从 AI 基础设施提供商 Fireworks AI 窃取凭证后，通过其市场分发了恶意 Claude Code 扩展程序。  
  
此次泄露事件还让攻击者得以访问内部系统并窃取客户数据，包括包含未编辑凭证的历史 AI 编码代理痕迹，这些痕迹后来被用于破坏其他服务。  
  
此次安全漏洞事件在周五发布的一份新的事件报告中披露，该报告解释了攻击者如何于 10 月 29 日通过 Cursor 的应用市场分发Anthropic 的 Claude Code 扩展程序的恶意版本。  
  
这次攻击使多达 5000 名开发人员面临恶意软件感染的风险，这些恶意软件会安装持久性 SSH 后门。  
  
Cursor 是一款基于微软开源 Visual Studio Code (VS Code) 的 AI 代码编辑器，允许开发人员使用 AI 助手编写、修改和调试软件。  
  
据 Cursor 称，此次攻击始于黑客获取了存储在 Fireworks AI 上的访问密钥，Fireworks AI 是一家用于 AI 模型训练和推理的第三方提供商。  
  
攻击者利用暴露的密钥从只读存储桶 Cursor 中复制数据，该存储桶用于与 Fireworks 共享信息。  
  
该存储桶包含历史人工智能编码代理的跟踪记录，大部分来自 2025 年，这些记录收集自未启用隐私模式的用户，其数据可用于模型训练。其中一些跟踪记录包含未编辑的 API 凭据，使攻击者能够访问其他 Cursor 系统。  
  
Cursor 表示，只有不到 0.05% 的用户存在代码代理痕迹泄露的情况，而只有不到 0.01% 的客户 API 凭证遭到泄露。  
  
利用泄露的凭证，黑客从 Cursor 的多个软件即服务 (SaaS) 工具中窃取了数据，其中包括：已存档的非生产环境 Cursor 源代码库，其中一些包含业务联系信息。客户支持信息和电子邮件沟通有限。产品使用指标和客户联系方式。人工智能编码代理对话的部分摘要。客户之前与 Cursor 支持团队分享的凭证。  
  
Cursor 表示，其监控系统检测到了未经授权的活动，导致该公司撤销了 Fireworks 访问密钥，轮换了暴露的凭证，并调查了其他未经授权的访问。  
  
随着调查的深入，Cursor 出于谨慎起见，暂时关闭了一些内部服务和产品服务。  
  
然而，攻击者已经获得了凭证，允许他们通过 Cursor 的市场分发扩展程序。  
  
10 月 29 日，黑客利用该凭证在 Cursor 的 VS Code 扩展市场上发布了 Anthropic 的 Claude Code 扩展的恶意副本。  
  
Cursor解释说：“10月29日，攻击者利用从我们内部系统泄露的数据中窃取的凭证，将Anthropic的Claude Code扩展程序的恶意、未经授权的副本直接放置在用于服务Cursor VS Code扩展程序市场的缓存中。”  
  
此次攻击并未损害 Anthropic 的合法扩展程序或 Cursor 使用的扩展程序市场 Open VSX。  
  
恶意扩展程序版本为 2.1.312 和 2.1.313，在 Cursor 将其移除之前，大约存在了 11 个小时。  
  
正如此前报道的那样，攻击者修改了合法的 Claude Code 扩展程序，以执行恶意 JavaScript，试图在开发人员的计算机上安装持久的 SSH 后门。  
  
该恶意软件收集系统信息，安装攻击者控制的 SSH 密钥，尝试启用 SSH 访问，并配置持久化机制以维持远程访问。  
  
然而，安全研究人员发现了编码错误，这些错误很可能导致后门程序无法在许多尚未启用 SSH 的 Windows 和 macOS 系统上运行。  
  
Cursor 估计，在泄露窗口期内请求受影响扩展程序版本的多达 5,000 名用户可能收到了恶意版本。  
  
该公司表示，其生产基础设施、官方应用程序版本、客户代码库以及启用隐私模式的用户的代码和提示均未受到影响。  
  
Cursor 表示，为了安全起见，它已将所有推理流量从 Fireworks 转移出去，撤销并轮换了暴露的凭证，重建了扩展市场，并重新部署了生产基础设施。  
  
在攻击期间安装或更新到受影响的 Claude Code 扩展的客户，建议遵循Cursor 的补救指南。黑色十月  
  
此次事件发生之际，正值针对人工智能开发者平台的一系列攻击浪潮之中，网络安全公司 Wiz 将其称为“人工智能开发者平台攻击浪潮” 。  
  
这些攻击的目标是开发基础设施，目的是窃取身份验证凭据，特别是那些提供对 AI 模型访问权限的凭据。  
  
被盗凭证被用于未经授权的人工智能推理，给受影响的客户造成了巨额费用，一些事件还与人工智能模型提炼的尝试有关。  
  
此次攻击影响了众多公司，包括Railway、Northflank、Lightning AI、OpenCode和Warp。  
  
在 Railway 公司，攻击者窃取了客户的身份验证密钥，这些密钥随后被用于生成约 74 万美元的欺诈性人工智能收费。OpenCode 也报告了 API 密钥泄露和未经授权的人工智能使用情况。  
  
Fireworks AI 也受到了影响，在 10 月份披露了多起安全漏洞，其中包括一起 API 密钥和令牌泄露事件，以及另一起攻击者通过被入侵的第三方云提供商访问开发机器的事件。  
  
Fireworks 事件也影响了其他客户，包括Notion，该公司最近披露，少数工作区的 AI 聊天记录遭到泄露。
